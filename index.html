Connect your database

Connect your shared database once per device so every device stays in sync.

  1. Go to console.firebase.google.com and add a project (free)
  2. Build, then Firestore Database, then Create database in production mode
  3. Build, then Authentication, then Get started and enable the Email/Password sign-in method
  4. Project settings, then "Your apps", then Add app, then Web (</>) and copy the firebaseConfig object shown

That doesn't look like a valid Firebase config — paste the whole object shown in your Firebase project settings.

You can paste the whole code snippet Firebase gives you (imports and all) — it'll pick out the config automatically. Paste the exact same config on every device to keep them in sync.
